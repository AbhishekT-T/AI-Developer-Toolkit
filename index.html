Privacy Policy

Last Updated: September 2026

Your privacy is our utmost priority. This Privacy Policy details how Resume Scanner Pro handles candidate and resume information:

1. Local In-Browser Processing

All resume text parsing, keyword extraction, and score calculations run directly in your web browser. We do not transmit, sell, or retain copies of your uploaded resumes or personal contact details on centralized databases.

2. Third-Party AI APIs

When you use advanced AI features (such as cover letter generation or code tools), requests are sent securely to the selected AI provider (Google, OpenAI, Anthropic, DeepSeek, or Groq) using SSL encryption according to their respective enterprise API privacy terms.

3. Cookies and Advertising

This website may display advertisements served by Google AdSense and its partners. Third-party vendors, including Google, use cookies to serve ads based on a user's prior visits to this website or other websites. Users may opt out of personalized advertising by visiting Google Ads Settings.

If you have questions regarding this policy, please reach out via the Contact section.

🚀 How to Host Free in 2 Minutes

This project is 100% static and zero-backend, making it completely free to host on all top hosting platforms:

Option A: Vercel (Recommended)

  1. Push this folder to a GitHub repository.
  2. Go to vercel.com and click "Add New Project".
  3. Select your GitHub repo and click Deploy. Done in 30 seconds!

Option B: Netlify

  1. Go to app.netlify.com/drop.
  2. Drag and drop this project folder directly onto the screen.
  3. Your site is instantly live on a custom .netlify.app domain!

Option C: GitHub Pages

  1. Push the code to GitHub.
  2. Go to Repo Settings → Pages.
  3. Set Branch to main and save.
